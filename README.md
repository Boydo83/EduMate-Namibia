# EduMate Namibia

**NIED-aligned Teacher Assistant for Namibia**

Free, offline-capable web app for generating:

- Lesson Plans
- Scheme of Work
- Assessments (with marking schemes)
- Teaching Notes

Built specifically for the **Namibian Curriculum (NIED)** — Junior Primary to Senior Secondary.

## Features

- Clean modern dashboard
- Profile & School name appears on every document
- 34+ subjects (including Namibian languages)
- Subject-aware content (Maths, Languages, Sciences, etc.)
- **PDF download** for every generated document
- Print & Copy support
- Generated materials library (saved in browser)
- Fully responsive (works on phone, tablet, desktop)
- No coins / no login required

## How to use

1. Open **[index.html](index.html)** in any modern browser
2. Go to **Profile & School** → enter your name and school
3. Choose a generator (Lesson Plan, Scheme of Work, Assessment, or Teaching Notes)
4. Fill in Grade, Subject, Topic → Generate
5. Download as **PDF**, Print, or Copy
